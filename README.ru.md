# Voxel Asset Registry

Локальный инструмент для процедурных блокаутов и игровых ассетов. Blender
собирает модели из компонентов, а веб-интерфейс позволяет менять параметры,
сравнивать варианты, проверять проекции и экспортировать GLB.

**Публичная альфа 0.1.0-alpha.2.** В поставку входят шесть учебных наборов,
Impressor и инструкция полного пайплайна на семи языках.

[English](README.md) · [HTML-инструкция](docs/guide/ru.html)

[Скачать альфу](https://github.com/Evafan1337/voxel-asset-registry/releases/tag/0.1.0-alpha.2):
исходники, готовые модели и автономная HTML-инструкция. В архиве моделей —
32 GLB и 224 проекции; для их импорта установка сервиса не нужна.
[Состав наборов](docs/STARTER_PACKS.md) · [План развития](docs/STARTER_ROADMAP.md).

**Файлы Blender:** открой **Releases → Assets** и скачай
[архив готовых `.blend`](https://github.com/Evafan1337/voxel-asset-registry/releases/download/0.1.0-alpha.2/voxel-asset-registry-starter-blends-0.1.0-alpha.2.zip).
Внутри 32 редактируемые сцены, преобразованных из опубликованных GLB:
итоговые меши, материалы и доступные анимации. Устанавливать сервис не нужно.
После распаковки открой `models/assets/zuk_truck/v011/model.blend`;
`v012` — вариант без внешних накладок над колёсными арками. Процедурные
рецепты находятся отдельно в этом репозитории. Паровая машина —
`models/components/mx_steam_engine/v002/model.blend`; запусти её пробелом. Оригинальные демо CC0:
можно использовать коммерчески без обязательного указания автора.

## Установка

Первая проверяемая платформа — Linux с Bash. Нужны Python 3.11+, Node.js
20.19+ или 22.12+ и Blender 5.1+. Проверка альфы проводится с Python 3.12,
Node.js 24 и Blender 5.2. Godot 4 нужен для дополнительных игровых проверок.

```bash
git clone https://github.com/Evafan1337/voxel-asset-registry.git
cd voxel-asset-registry
./run.sh
```

Открой **http://127.0.0.1:8000**. Первый запуск устанавливает зависимости и
собирает интерфейс; для установки нужен интернет. Выбери `mt_truck/v001`
во вкладке ассетов и запусти сборку. Рецепты уже включены, модели собираются
по запросу и сохраняются в локальном кэше.
Инструкция доступна по **http://127.0.0.1:8000/guide/ru.html** и через кнопку
руководства в интерфейсе.

Путь к Blender при необходимости укажи в игнорируемом `config.local.yaml`:

```yaml
blender_bin: /path/to/blender
```

Все настройки описаны в [config.example.yaml](config.example.yaml). Сервис
по умолчанию доступен только на этом компьютере. Он рассчитан на локальную
работу автора; публичному серверу нужны отдельная авторизация и настройка.

## Учебные наборы

| Набор | Содержание |
| --- | --- |
| `zuk_truck` | Три стадии разработки грузовика и сравнение решения арок |
| `td` | Три башни, три противника, укрытие и дорожный тайл |
| `mt_truck` | Пять стадий грузовика из переиспользуемых компонентов |
| `evo_truck` | Витрина эволюции и отдельные варианты `vh_truck` |
| `evo_heli_light` | Витрина эволюции и отдельные варианты `vh_heli_light` |
| `steam_engine` | Паровая машина с вырезом в цилиндре: поршень, шатун, кривошип, золотник и регулятор движутся от одного угла вала; три пресета |

Компоненты и родительские рецепты включены. Точные демонстрационные цели
сборки перечислены в [манифесте](release/starter-packs.yaml).

```bash
.venv/bin/python -m registry doctor --require-blender
.venv/bin/python -m registry check
.venv/bin/python -m registry build-demo --list
.venv/bin/python -m registry build-demo --pack mt_truck
```

Редактирование сохраняй новым дочерним вариантом. После сборки проверь
отчёт, шесть ортографических видов и изометрию. Успешные проверки геометрии
не означают автоматическое одобрение модели человеком.

## Impressor и материалы

```bash
.venv/bin/python -m impressor sketch impressor/templates/sketch_brief.example.yaml \
  --out var/impressor/truck_sheet_r001
```

Команда подготавливает промпт и запрос, картинку создаёт агент с ImageGen.
Первый проход — кубы и прямоугольные блоки. Запроси шесть ортографических
проекций и изометрию; затем проверь согласованность по одной настоящей
3D-модели. Картинка генератора остаётся гипотезой до проверки.

Material Lab позволяет сравнивать toon-пресеты на моделях публичного
набора. Палитра и классы поверхностей задаются рецептами. Экспорт в Godot
выполняется после сборки выбранного варианта:

```bash
.venv/bin/python -m registry export-godot /path/to/godot-project assets/mt_truck/v005
```
