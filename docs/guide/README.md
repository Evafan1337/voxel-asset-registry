# Руководство по пайплайну

Открой [index.html](index.html) в браузере. Интернет и сервер Registry для чтения
не нужны. Внутри есть переключатель языка, оглавление, копирование промптов,
ссылки на полноразмерные изображения и печать в PDF.

Отдельные страницы открываются сразу на выбранном языке и содержат текст даже
при отключённом JavaScript:

- [Русский](ru.html)
- [English](en.html)
- [Español](es.html)
- [Português](pt-BR.html)
- [简体中文](zh-Hans.html)
- [Français](fr.html)
- [Deutsch](de.html)

Переведено руководство; скриншоты показывают текущий русский интерфейс.
Для установки, генерации и сборки нужен сам проект и инструменты, указанные
в руководстве. Локальный компилятор Impressor подготавливает запрос;
изображение создаёт агент встроенным ImageGen.

## Источники и пересборка

Тексты находятся в `locales/*.json`, оформление — в `template.html`,
реальные скриншоты — в `assets/`. `assets/screenshots.json` фиксирует маршруты,
размер экрана и время съёмки. `cube-reference-sheet.png` — предложение ImageGen,
сохранённое также с промптом и проверкой в
[примере Impressor](../../impressor/examples/truck_cube_sheet_r001/README.md).
В нём обнаружены расхождения проекций, поэтому он не обозначен точным чертежом.

Из корня проекта:

```bash
.venv/bin/python docs/guide/build.py
```

Сборка использует только стандартную библиотеку Python. Она создаёт страницы
на семи языках и `index.html`, встраивает все переводы для переключателя и
обновляет копии контрактов и YAML в `resources/`. Изображения остаются отдельными
файлами; при переносе руководства сохраняй всю папку `docs/guide/`.

Перед публикацией переводы полезно проверить носителям соответствующих языков.
Руководство описывает текущую альфу и явно отделяет запланированные возможности.
